# UI / Frontend

This folder is reserved for the repository's user interface code.

Recommended structure:

- `ui/package.json` or `ui/pyproject.toml` for frontend dependencies
- `ui/src/` for application source files
- `ui/public/` or `ui/static/` for public assets
- `ui/README.md` for UI-specific setup instructions

Keep frontend code separate from backend logic in `src/` and from tests in `tests/`.
